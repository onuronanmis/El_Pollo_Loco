# 🐔 El Pollo Loco

🇩🇪 [Deutsch](#deutsch) | 🇬🇧 [English](#english)

## Deutsch

Ein 2D-Jump-'n'-Run-Spiel in Vanilla JavaScript, entstanden als Projekt der Developer Akademie.

### Story

In einem kleinen Wüstendorf in Mexiko sind die Hühner verrückt geworden. Angeführt von einem riesigen Monster-Huhn überrennen sie das Dorf. Nur einer stellt sich ihnen entgegen: **Pepe Peligroso**! Mit scharfen Salsa-Flaschen und seiner alten Walze, die Hühner in leckere Keulen verwandelt, zieht er los, um das Dorf zu retten.

### Features

- Hühner und Küken mit zufälliger Geschwindigkeit, besiegbar per Sprung oder Flaschenwurf
- Endboss mit Alarm-, Angriffs-, Treffer- und Todesanimation sowie eigener Lebensanzeige
- **Walze:** Hühner, die hineinlaufen, werden zu Keulen (+10 Leben)
- Münzen sammeln: 5 Münzen ergeben eine Flasche (maximal 5 Flaschen)
- Rückstoß bei Kontakt mit Gegnern
- Idle- und Schlafanimation mit Schnarchen
- Hintergrundmusik, Bossmusik und Soundeffekte, Mute-Einstellung wird gespeichert
- Pause, Neustart und Hauptmenü ohne Neuladen der Seite
- Vollbildmodus
- Mobile Steuerung per Touch-Buttons, Hinweis zum Drehen im Hochformat

### Steuerung

| Taste | Aktion |
|---|---|
| A / ← | Nach links |
| D / → | Nach rechts |
| W / ↑ | Springen |
| Leertaste | Flasche werfen |
| P | Pause |

Auf Smartphone und Tablet erscheinen Touch-Buttons.

### Technik

- HTML5 Canvas
- Vanilla JavaScript (objektorientiert, eine Klasse pro Datei)
- CSS (responsiv, Querformat auf Mobilgeräten)

### Starten

Repository klonen und `index.html` im Browser öffnen, zum Beispiel mit der VS-Code-Erweiterung Live Server.

## English

A 2D jump 'n' run game built with vanilla JavaScript as a Developer Akademie project.

### Story

In a small desert village in Mexico, the chickens have gone crazy. Led by a giant monster chicken, they are overrunning the village. Only one man stands in their way: **Pepe Peligroso**! Armed with hot salsa bottles and his old grinder, which turns chickens into tasty drumsticks, he sets out to save the village.

### Features

- Chickens and chicks with random speed, defeated by jumping on them or throwing bottles
- Endboss with alert, attack, hurt and death animations and its own health bar
- **Grinder:** chickens that walk into it become drumsticks (+10 health)
- Collect coins: 5 coins turn into one bottle (max. 5 bottles)
- Knockback on enemy contact
- Idle and sleep animation with snoring
- Background music, boss music and sound effects, mute setting is saved
- Pause, restart and main menu without reloading the page
- Fullscreen mode
- Mobile touch controls, rotate hint in portrait mode

### Controls

| Key | Action |
|---|---|
| A / ← | Move left |
| D / → | Move right |
| W / ↑ | Jump |
| Space | Throw bottle |
| P | Pause |

Touch buttons appear on smartphones and tablets.

### Tech

- HTML5 Canvas
- Vanilla JavaScript (object-oriented, one class per file)
- CSS (responsive, landscape mode on mobile devices)

### Getting Started

Clone the repository and open `index.html` in your browser, for example with the VS Code extension Live Server.
